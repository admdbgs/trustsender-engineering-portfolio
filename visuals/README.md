# Visuals

This directory documents the visual language for the public architecture whitepaper, including future layout, typography, and dark-mode presentation guidance.

Structurizr DSL remains the canonical public architecture model. D2 is used only as the presentation layer for the main engineering overview, derived from the approved model rather than replacing it.

`trustsender-engineering-overview.d2` defines the first dark-mode D2 engineering overview source. The generated D2 SVG is initially a temporary CI preview artifact only. Generated output must not be committed automatically, and it must not be published from `build/` or copied into `diagrams/` without review.

Publication requires visual inspection, public-safety inspection, and an explicit reviewed commit in a separate publication change.
