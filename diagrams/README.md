# Diagrams

This directory contains reviewed, publication-ready SVG architecture diagrams derived from approved, sanitized architecture models.

Published diagrams:

- [`trustsender-system-context.svg`](trustsender-system-context.svg) — people and external systems that interact with TrustSender.io.
- [`trustsender-container-view.svg`](trustsender-container-view.svg) — operational containers and the distinctly `ONGOING` P2 SMTP evolution.
- [`trustsender-engineering-overview.svg`](trustsender-engineering-overview.svg) — reviewed Structurizr manual Flow Graph with P1 operational and P2 explicitly `ONGOING`.

The diagrams can be opened individually at full SVG resolution. The Engineering Overview, System Context, and Container View are also embedded in the public portfolio surface.

Publication requires model validation, visual inspection, public-safety inspection, and reviewed approval of the output. Generated CI previews are temporary review aids. Only the explicitly reviewed SVGs in this directory are publication outputs.
