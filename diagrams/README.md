# Diagrams

This directory is reserved for reviewed architecture diagrams derived from approved models. Publication-ready diagrams will use SVG so they remain accessible, scalable, and suitable for the public whitepaper.

Publication-ready SVGs will eventually live in this directory. CI preview artifacts are temporary review aids and are not automatically approved for publication.

Publication requires a human review gate that includes:

1. model validation;
2. visual inspection;
3. public-safety inspection; and
4. an explicit reviewed commit of the approved output.

No generated SVG is published in this task. Future diagram changes must avoid private identifiers and remain reviewable through pull requests.
