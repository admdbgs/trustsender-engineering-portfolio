# Diagrams

This directory contains reviewed, publication-ready SVG architecture diagrams derived from the approved, sanitized Structurizr model.

Published diagrams:

- [`trustsender-system-context.svg`](trustsender-system-context.svg) — people and external systems that interact with TrustSender.io.
- [`trustsender-container-view.svg`](trustsender-container-view.svg) — operational containers and the distinctly `ONGOING` P2 SMTP evolution.

The diagrams are embedded directly in the repository README and can also be opened individually at full SVG resolution.

Publication requires:

1. model validation;
2. visual inspection;
3. public-safety inspection; and
4. an explicit reviewed commit of the approved output.

Generated CI previews are temporary review aids. Only the explicitly reviewed SVGs in this directory are publication outputs.
