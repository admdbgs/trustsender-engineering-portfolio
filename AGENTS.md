# Public Repository Guidelines

## Scope and safety

This repository is public and sanitized. All architectural statements must be grounded in approved information and must avoid unsupported inference.

Never add secrets, private infrastructure identifiers, proprietary code, raw repository exports, commercial algorithms, security-sensitive configuration, or unverified metrics. Public content must not expose production source code or internal documentation.

## Architecture and publication

Structurizr DSL will be the canonical architecture model. D2 will be the presentation layer for the main visual diagram, and SVG will be the publication format.

P2 must be labeled **ONGOING** until that status is explicitly changed through an approved review. Do not imply that P2 SMTP validation is operational.

## Contribution requirements

All generated changes must be reviewable through a pull request. Do not merge generated output without review.

English is required for all public repository content.
